Smart Academic Tracker

A modern college management and attendance tracking web application built with HTML, CSS, JavaScript, Tailwind CSS, and Firebase. This platform helps students and faculty manage academic activities through a single interactive dashboard.

Features
Student & Faculty Authentication
Smart Attendance Management
Leave Planner with Attendance Prediction
Subject-wise Performance Tracking
Catch-Up Bot for Missed Classes
College Events Management
Lost & Found Portal
Faculty Dashboard for Attendance Updates
Firebase Authentication & Firestore Integration
Responsive Glassmorphism UI Design
Real-time Event & Attendance Handling
